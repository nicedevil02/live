# اپلیکیشن تلویزیون طلالایو (TalaLive TV) — نسخه ۲.۰.۰

اپلیکیشن اندرویدی مستقل و ویژهٔ تلویزیون‌های هوشمند و اندروید باکس‌ها برای نمایش لحظه‌ای نرخ طلا، سکه، ارز و ویترین محصولات طلافروشی در مغازه.

---

## ۱. معماری دوحالته (Dual-Engine Architecture)

این اپلیکیشن بر پایهٔ معماری هیبریدی مقاوم طراحی شده است که دو موتور رندر موازی دارد:

```
                      ┌────────────────────────────────────────┐
                      │          BoardActivity (Controller)    │
                      └───────────────────┬────────────────────┘
                                          │
                  ┌───────────────────────┴───────────────────────┐
                  ▼                                               ▼
      ┌───────────────────────┐                       ┌───────────────────────┐
      │   حالت نیتیو (NATIVE)   │                       │     حالت وب (WEB)     │
      │    [مسیر پیش‌فرض]      │                       │     [حالت ثانویه]     │
      ├───────────────────────┤                       ├───────────────────────┤
      │ • رندر خالص با View   │                       │ • رندر وب‌ویو Chrome  │
      │ • فونت وزیری فارسی    │                       │ • نمایش زنده URL سایت │
      │ • بدون وابستگی DPI    │                       │ • واچ‌داگ و ریکاوری   │
      │ • مصرف رم ۲۵-۳۵ مگ    │                       │ • مصرف رم ۱۲۰-۱۸۰ مگ  │
      └───────────────────────┘                       └───────────────────────┘
```

### ۱.۱. تابلوی نیتیو (`NativeBoardView`) — مسیر پیش‌فرض و اصلی
- **رندر ۱۰۰٪ مستقل از سیستم‌عامل:** بدون وابستگی به وجود یا نسخهٔ `Android System WebView`.
- **فونت فارسی یکپارچه:** فونت وزیرمتن (`Vazirmatn`) به صورت توکار درون برنامه قرار دارد و نمایش روی تمام باکس‌های چینی بدون فونت فارسی بدون نقص است.
- **مقیاس‌بندی نسبی (`Scale.kt`):** کلیه ابعاد و فونت‌ها کسری از ارتفاع واقعی نمایشگر هستند؛ تغییرات DPI و باگ‌های density اندروید باکس‌ها چیدمان را به هم نمی‌زند.
- **کش آفلاین فوری:** در زمان استارت‌آپ ابتدا نرخ‌های قبلی کش‌شده بلافاصله نمایش داده شده و تابلوی مغازه هرگز صفحه خالی نشان نمی‌دهد.
- **اسلایدشوی محصولات (`ImageCache.kt`):** دانلود، کش و چرخش خودکار محصولات با انیمیشن Fade و مقیاس‌بندی استاندارد به منظور جلوگیری از کرش `OutOfMemoryError`.
- **محافظت از سوختگی پیکسل (Pixel Shift):** هر ۱۵ دقیقه کل تابلو یک الی دو پیکسل نامحسوس جابه‌جا می‌شود تا اثر ثابت بر روی پنل‌های OLED و LCD باقی نماند.

### ۱.۲. تابلوی وب (`WebView`) — مسیر جایگزین
- پشتیبانی کامل از قابلیت‌های تابلوی وب در مرورگر برای دستگاه‌های با وب‌ویوی مدرن (Chrome 80+).
- مجهز به سپر امنیتی SSL (`N-01`)، بررسی نسخه با ریفلکشن بدون کرش (`WebViewProbe.kt`)، حاشیه امن تصویر قابل تنظیم (Overscan 0%..7%).

## ۲. منطق انتخاب حالت رندر و سوییچ اضطراری

ترتیب اولویت تصمیم‌گیری در شروع برنامه:
1. **پرچم اجباری محلی (`forced_native == true`):** اجرا در حالت `NATIVE`.
2. **دستور مستقیم سرور (`server_render_mode == "web"`):** اجرا در حالت `WEB`.
3. **حالت خودکار سرور (`server_render_mode == "auto"`):** در صورت وجود نسخه مدرن وب‌ویو ($\ge 70$) حالت `WEB` و در غیر این صورت `NATIVE`.
4. **پیش‌فرض کلی سامانه:** حالت `NATIVE`.

### شرایط سوییچ خودکار اضطراری از وب به نیتیو:
اگر اپ در حالت وب باشد، در صورت وقوع هر یک از خطاهای زیر بلافاصله و بدون وقفه به تابلوی نیتیو سوییچ می‌کند:
* عدم وجود یا غیرفعال بودن پکیج WebView بر روی دستگاه (`probe.available == false`).
* نسخهٔ بسیار قدیمی وب‌ویو (`probe.majorVersion in 1..69`).
* بروز هرگونه `Exception` در زمان ساخت شیء `WebView`.
* دو بار متوالی انقضای تایم‌اوت بارگذاری اولیه (Watchdog 25s).
* وقوع ۳ بار کرش رندر (`onRenderProcessGone`) در مدت زمان یک ساعت.

## ۳. کنترل دستی با ریموت کنترل

در هر لحظه با استفاده از ریموت کنترل تلویزیون:
- **دکمه Menu** یا **نگه داشتن کلید OK / Enter به مدت ۳ ثانیه**: منوی تنظیمات باز می‌شود.
- گزینه‌های منو:
  - بازخوانی مجدد تابلو
  - سوییچ بین حالت نیتیو و حالت وب
  - مشخصات کامل دستگاه (نام گالری، نسخه برنامه، نسخه وب‌ویو، حالت فعال)
  - تنظیم حاشیه امن تصویر (Overscan: ۰٪، ۳٪، ۵٪، ۷٪)
  - قطع اتصال دستگاه
- **دکمه Back (دو بار متوالی)**: خروج از اپلیکیشن.

---

## ۴. تله‌متری و نظارت از پنل ادمین

با هر پالس نبض (Heartbeat)، دستگاه آخرین وضعیت فنی خود را به پنل ارسال می‌کند:
- حالت رندر فعال (`render_mode`: `native` یا `web`)
- دلیل سوییچ به نیتیو (`fallback_reason`: مثلاً `startup_check`, `watchdog_double_timeout`, `user_menu_toggle`)
- نسخه اپلیکیشن، نگارش اندروید و نسخه وب‌ویو.
مدیر سیستم در پنل مدیریت طلالایو در بخش «تلویزیون‌های من» وضعیت دقیق اتصال هر تلویزیون را رصد می‌کند.
