# سامانهٔ جامع تابلو و تحلیل نرخ طلالایو (TalaLive.ir)

طلالایو یک سامانهٔ پیشرفته، سریع و یکپارچه برای نمایش زنده و برخط نرخ‌های طلا، مسکوکات و ارز ویژهٔ مغازه‌ها و گالری‌های طلافروشی است. این پروژه شامل سامانهٔ ابری تحت وب لاراول و اپلیکیشن سبک و اختصاصی تلویزیون‌های هوشمند (Android TV) می‌باشد.

---

## 🏛 معماری پروژه

1. **بک‌اند و هستهٔ مرکزی (Laravel 11):**
   - سرویس فوق سریع و مقاوم خواندن اسنپ‌شات قیمت‌ها از کش (`MarketService`) با پینگ زیر ۸ میلی‌ثانیه.
   - مدیریت نشست‌ها، کدهای فعال‌سازی ۶ کاراکتری بدون حروف گیج‌کننده، و جفت‌سازی سخت‌افزاری (`tv_devices`).
   - سرویس ضربان قلب (`/api/tv/heartbeat`) جهت مانیتورینگ اتصال، گزارش نسخه و آپدیت خودکار تلویزیون‌ها.
   - تابلوهای زنده مبتنی بر Alpine.js با بهینه‌سازی اختصاصی صفحهٔ تلویزیون (حالت TV Mode، مارجین Overscan، مخفی‌سازی ماوس و پل ارتباطی نیتیو `window.TalaTV`).

2. **اپلیکیشن اختصاصی تلویزیون (`tv_app_native/`):**
   - توسعه داده شده با کاتلین خالص و فریم‌ورک استاندارد اندروید **بدون حتی یک کتابخانهٔ جانبی (Zero-Dependency)**.
   - حجم فوق‌العاده سبک فایل نصبی نهایی: **تنها ~۴۹ کیلوبایت**.
   - مجهز به واچ‌داگ سلامت ۲۵ ثانیه‌ای وب‌ویو و ۵ دقیقه‌ای تپش قیمت‌ها (`TalaTvBridge`).
   - لایهٔ آفلاین نیتیو با شمارشگر معکوس و بازگشت خودکار به محض وصل شدن اینترنت.
   - سیستم جفت‌سازی هوشمند با QR Code پویا و ارسال کد از طریق پیامک به گوشی طلافروش.
   - سیستم آپدیت درون‌برنامه‌ای با اعتبارسنجی یکپارچگی و امضای دیجیتال پکیج.

## 🛠 راهنمای کامپایل و بیلد اپلیکیشن تلویزیون (`tv_app_native`)

### پیش‌نیازها:
- JDK 17 یا بالاتر
- Android SDK (API Level 34)

### دستورات کامپایل نسخه Release:

```powershell
# ورود به پوشه اپلیکیشن
cd tv_app_native

# تنظیم متغیرهای محیطی کی‌استور امضا (اختیاری؛ در صورت عدم تنظیم از مقادیر پیش‌فرض توسعه استفاده می‌شود)
$env:TALA_KEYSTORE_PATH = "C:\path\to\talalive-tv-release.jks"
$env:TALA_KEYSTORE_PASSWORD = "your_keystore_password"
$env:TALA_KEY_ALIAS = "talalive"
$env:TALA_KEY_PASSWORD = "your_key_password"

# اجرای بیلد با گریدل
.\gradlew.bat assembleRelease
```

فایل خروجی امضاشده در مسیر زیر تولید می‌شود:
`tv_app_native/app/build/outputs/apk/release/app-release.apk`
